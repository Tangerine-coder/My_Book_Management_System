基于 C++ 面向对象思想实现的**控制台图书管理系统**。用 `Book` 类封装图书信息，用 `vector<Book>` 作为内存数据表，对外提供增删改查、借阅归还、全量展示等业务功能，并通过 `books.txt` 完成数据的启动加载与退出保存。

项目按「先跑通功能、再补交互、最后做持久化」的思路逐步迭代，代码量不大，适合作为 C++ 入门练手、课程设计作业或 GitHub 上的第一个 C++ 仓库。

---

## 功能特性

| 菜单 | 功能 | 实现要点 |
| :--: | :--- | :--- |
| 1 | 新增图书 | 依次录入编号、书名、作者、库存；编号重复会被拒绝，书名/作者支持空格 |
| 2 | 查询图书 | 支持按编号、按书名两种方式精确查询，未命中给出提示 |
| 3 | 修改图书 | 按编号或书名定位后修改库存，库存为负会被拦截 |
| 4 | 删除图书 | 按编号或书名定位并从列表中移除 |
| 5 | 借阅图书 | 按编号或书名借书，库存大于 0 才能借出，否则提示「库存不够」 |
| 6 | 归还图书 | 按编号或书名还书，库存 +1 |
| 7 | 显示全部 | 输出表头后逐行打印编号、书名、作者、库存 |
| 0 | 保存并退出 | 将内存数据写回 `books.txt` 后退出程序 |

**体验与健壮性**

- **数字输入容错**：菜单选项、编号、库存全部使用 `cin >> int` + 失败重试，输入字母不会陷入死循环
- **整行读取**：书名、作者用 `getline` 读取并裁剪首尾空白，可以录入《老人与海》这类带空格或外文书名
- **中文显示**：Windows 下通过 `SetConsoleOutputCP(CP_UTF8)` / `SetConsoleCP(CP_UTF8)` 修正控制台乱码
- **异常数据容错**：加载时跳过空行、字段数不符、编号或库存非数字的行，不影响其余数据

## 数据存储

所有图书保存在根目录的 `books.txt` 中，**一行一本，字段用英文逗号分隔**，顺序固定为 `编号,书名,作者,库存`：

```text
1001,三体,刘慈欣,1
1002,老人与海,欧内斯特 海明威,1
1003,局外人,阿尔贝 加缪,1
1004,巴黎圣母院,维克多 雨果,1
```

**加载规则**（`load()`）：

1. 读取前先 `bookList.clear()`，避免重复加载
2. 空行直接跳过
3. 按 `,` 切分后字段数不等于 4 时，打印该行并跳过
4. `编号`、`库存` 用 `stoi` 转换，失败或越界时用 `try...catch` 捕获并跳过该行
5. 文件不存在视为首次运行，程序继续启动并提示

**保存规则**（`save()`）：仅在选择 `0` 退出时触发，按同样格式覆盖写回。

## 设计说明

**类的职责划分**

```text
Book
├─ id      : int      // 图书编号，唯一
├─ name    : string   // 书名
├─ author  : string   // 作者
├─ stock   : int      // 库存
├─ borrow()   : bool  // 库存 > 0 时自减并返回 true
├─ giveBack() : void  // 库存自增
└─ showInfo() : void  // 打印单本图书信息
```

- **封装**：属性全部私有，只能通过 `getXxx()` / `setXxx()` 访问；借书、还书这类会改变自身状态的行为放在类内部，而不是散落在业务函数里
- **数据层**：`vector<Book>` 作为内存数据表，业务函数统一以 `vector<Book> &` 引用传参，避免整体拷贝
- **文件层**：`load()` / `save()` 与业务逻辑解耦，内存操作失败不会污染磁盘数据
- **健壮性**：数字输入统一采用「`cin` 失败 → `clear()` → 丢弃整行缓冲 → 重新提示」的模板；字符串转换统一 `try...catch`
- **跨平台**：Windows 相关头文件与代码页设置用 `#ifdef _WIN32` 包裹，其他平台不受影响

## 已知限制

- 修改功能目前只能改库存，书名、作者需要删除后重新录入
- 按书名匹配为**精确匹配**，且同名图书只会命中列表中的第一本
- 字段中不能包含英文逗号，否则会被当成字段分隔符
- 展示使用 `\t` 对齐，中英文混排时列宽仍可能不齐
- 借还只改变库存，不记录借阅人、借阅时间等流水信息
- 删除、修改没有二次确认
- 新增图书时未拦截负库存（修改时已拦截）
